OpenWand v0.12.2

**Changed:**

- Updated model lists and suggested defaults across providers.
- Updated public web search for local and compatible cloud models without a separate search API key. Cloud models still require their usual account or API access.
- Provider errors now identify their source and show the original message, with sensitive details redacted. Technical details can be expanded when needed.
- Public search-source URLs stay readable, while credentials and private URL content remain protected.
- Applied the final rounded OW icon across the app, website, demos, and Store listing assets.

**Fixed:**

- Improved tool-call handling and multi-step file operations across supported providers.
- Fixed the chat window's waiting indicator for prompts sent through the overlay.
- Kept completed file operations when the model's reply subsequently fails, with a notice to check the file before retrying.
- Prevented the shared completion check from requesting a completed native search again.
- Added the new status and error-detail labels in Spanish, French, Simplified Chinese, and Traditional Chinese.

**Compatibility:**

- Retired GitHub Models connections show a clear notice to choose another provider.
- Model availability and tool support depend on the selected provider, account, and model.
