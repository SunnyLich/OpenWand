# OpenWand 0.12.0 — Windows installer transition

Windows now has a signed, offline EXE installer with a Start Menu entry and a
registered Windows uninstaller. The transition release also includes a ZIP so
existing portable installations can reach the new updater.

## If you use the current Windows ZIP

1. In OpenWand, open **Settings > About** and apply the offered update.
   The updater applies the transition ZIP, installs the signed EXE silently,
   and reopens the installed app automatically.
2. The old portable folder remains as a backup. Its shortcut opens the installed
   copy while that installation exists. OpenWand copies its user add-ons
   to `%APPDATA%\OpenWand\addons` without overwriting existing add-ons. Your
   settings and chats already live in user data and stay in place.
3. If installation fails, the updated portable copy reopens and remains usable.
   Its installer controls in Settings provide a recovery path.
4. After checking the installed copy, you can manually remove the old portable
   folder. Use the installed app's **Uninstall OpenWand** action for a complete
   uninstall, or Windows Settings to remove only the installed app files.

Installed Windows releases use signed installers for later in-app updates.
macOS and Linux release formats are unchanged.

## Other fixes

- Preserve complete multiline action prompts when editing them in Settings.
- Preserve literal prompt text, including quotes, surrounding spaces, and
  `${...}`, when saving settings. Replace complete legacy multiline `.env`
  values without leaving stray settings behind.
- Report invalid action field types without crashing the action catalogue.
- Preserve the virtual environment Python path in source launcher smoke tests.
- Handle complete AI tool calls that compatible providers finish with `stop`.
