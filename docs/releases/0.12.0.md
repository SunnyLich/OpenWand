OpenWand v0.12.0

**Changed:**

- Switched Windows installation to a signed EXE installer with an included runtime, a Start Menu shortcut, and a registered Windows uninstaller. Python does not need to be installed separately.
- Added automatic migration for existing Windows ZIP users through the in-app updater. OpenWand installs the signed release and reopens automatically, preserving settings, chat history, and user add-ons.
- Kept the previous portable folder as a backup and redirected its launcher to the installed app.
- Added a recovery path that reopens the updated portable copy if installation fails.
- Updated installed Windows copies to use signed EXE installers for future updates.
- Added installer and recovery translations for Spanish, French, Simplified Chinese, and Traditional Chinese.
- Clarified privacy disclosures and added a dedicated privacy-policy page.
- Kept the existing macOS and Linux installation formats.

**Fixed:**

- Fixed Windows ZIP updates failing because the portable application folder was still locked. Updates now replace files in place without renaming the folder.
- Fixed startup failures caused by stale worker-process information after an update.
- Fixed multiline action prompts being truncated when edited in Settings.
- Fixed saved prompts losing quotes, surrounding spaces, or literal `${...}` text.
- Fixed leftover lines from older multiline settings entries remaining after saving.
- Fixed malformed action fields crashing the action catalogue.
- Fixed complete AI tool calls being dropped by some OpenAI-compatible providers.
- Improved clipboard fallback in recognised Linux terminals.
- Fixed source-launch checks losing the project's Python virtual environment.
- Expanded and stabilised installer, migration, rollback, uninstall, and cross-platform release checks.

**Updating from a Windows ZIP installation:**

Open **Settings → About**, select **Check for updates**, then **Download update** and **Apply update**. Migration to the installed version happens automatically.

For a new Windows installation, download **OpenWand-v0.12.0-windows-x64-setup.exe**. The Windows ZIP remains available for compatibility with older updaters.
