OpenWand v0.12.3

**Changed:**

- Windows installers detect the registered installation, show installed and bundled versions, and offer update, same-version repair/reinstall, downgrade, or uninstall. Downgrades display a heads-up with a choice to continue or cancel; silent installs log the notice and proceed.
- Interactive setup starts with a welcome confirmation, then language selection. Installer pages, version notices and uninstall messages support English, Traditional Chinese, Simplified Chinese, Spanish and French. Version notices appear after language selection.
- Reset All now clears OpenWand-owned settings, chats, memory, add-ons, optional packages and saved sign-ins, then closes the app for a fresh start.
- Uninstall confirmations let you choose whether to keep OpenWand data for a future reinstall or remove it, with the affected paths shown before confirmation. External providers, other apps' sign-ins and shared caches are preserved.
- Chat and the floating reply bubble share response state, keeping streamed text, cancellation and provider errors consistent between views.

**Fixed:**

- Bundled trusted certificate roots for verified update checks and downloads, addressing certificate failures in packaged installations.
- Restored live reply previews while keeping approved add-on response transformations authoritative. Automatic speech no longer repeats cumulative previews, and final annotations and thought filtering are preserved.
- Fixed add-on settings reopening with stale values, lost concurrent setting changes, Chat before-query hooks, tray actions and failed installations incorrectly reporting success.
- Prevented agent runs cancelled during a model request from being recorded as successful.
- Isolated Windows build DLL discovery to prevent unrelated system tools from introducing incompatible Qt dependencies.
- Removed unnecessary hostname lookups when starting the local Shared Workspace bridge.
- Updated reset and uninstall translations in Spanish, French, Simplified Chinese and Traditional Chinese.

**Validation and development:**

- Added whole-app journey tests for local development and GitHub Actions, using explicit external-service fixtures and disposable profiles.
- Production packages exclude the full journey tooling. Release checks exercise a test build, then rebuild and smoke-test the production package.
- Added isolated development-installer checks for installation, reinstall, default data retention and explicit data and credential removal.

**Validation limits:**

- The downgrade notice applies to installers built with the new check. Previously published installers such as 0.12.2 do not gain it retroactively. Allowing a downgrade does not guarantee that an older app can read data saved by a newer version.
- If certificate verification prevents an older installation from checking or downloading updates, install the new setup manually over the existing installation while retaining saved data. The new updater's certificate fix cannot run before the old client downloads it.
- Hosted journeys use fixture providers, credentials, browser callbacks and desktop input; they do not establish live-account or native-permission coverage.
- Native uninstall-dialog visual review and final signed-release validation remain separate checks.
