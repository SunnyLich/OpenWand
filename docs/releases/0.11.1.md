# OpenWand 0.11.1

Chat improvements and bug fixes since 0.11.

- Refresh the chat workspace with a growing message box, attachment previews,
  configurable Enter behavior, saved window geometry, and controlled scrolling
  while replies stream.
- Improve local Codex and Claude Code history imports and clarify that imports
  do not synchronize with web conversations.
- Reuse the configured Codex environment, expose skills and subagent activity,
  and handle agent questions, permission requests, and MCP input requests.
- Add optional settings to open Chat for prompts and suppress the floating reply
  bubble when Chat opens automatically. Both settings default to off.
- Allow retries after temporary model failures while respecting provider rate
  limits, with clearer error messages and retry timing.
- Keep text chat available when the audio worker cannot start, and improve worker
  exit diagnostics and optional speech dependency checks in packaged builds.
- Make public web tools independently configurable and improve setup controls,
  model labels, and checkbox visibility.
- Complete new UI translations in Spanish, French, Simplified Chinese, and
  Traditional Chinese. Repair test isolation and refresh the chat visual baseline.
- Audit and verify Windows bundle signatures during release packaging.
