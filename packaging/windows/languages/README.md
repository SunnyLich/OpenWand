Both cover the full message set of the pinned Inno Setup 6.7.3 compiler, which
does not bundle these files. Upstream author credits remain in their headers;
the upstream license is included as LICENSE-Inno-Setup.txt. English, Spanish,
and French use the files bundled with that pinned compiler. No translations
are downloaded during installer builds.
