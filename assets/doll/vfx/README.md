# OpenWand state VFX

The widget plays a finished third-party center-out ripple animation. It does
not draw its own waveform, particles, or procedural effects.

## Speaking ripple

- App asset: `speaking-ripple.webp`
- Archived source asset: `speaking-ripple.lottie`
- Source animation: "Circle Pulse" by Abraham Monroy on LottieFiles
- Source: https://lottiefiles.com/free-animation/circle-pulse-g74b2lbc5C
- License: Lottie Simple License
- Processing: recolored from green to white, center-cropped, resized, and
  converted to lossless animated WebP with alpha. The artist's shapes, motion,
  timing, and frame order are unchanged.
