# Security Policy

## Supported Versions

Security fixes are made against the latest OpenWand release and the current default branch. Older releases may be asked to update before a report can be reproduced or fixed.

## Reporting a Vulnerability

Please do not disclose a suspected vulnerability in a public issue, discussion, pull request, log, or screenshot.

Use [GitHub's private vulnerability reporting form](https://github.com/SunnyLich/OpenWand/security/advisories/new) when it is available. Include:

- The affected OpenWand version, operating system, and installation type.
- A concise description of the issue and its potential impact.
- Reproduction steps or a minimal proof of concept.
- Any mitigations you have already identified.

Remove API keys, OAuth tokens, personal information, captured desktop context, and unrelated log content. If GitHub's private reporting form is unavailable, open a public issue containing no vulnerability details and ask the maintainer to establish a private contact method.

Reports will be reviewed as time permits. Confirmed issues will be addressed in the current codebase and disclosed publicly after a fix is available when disclosure is appropriate.
